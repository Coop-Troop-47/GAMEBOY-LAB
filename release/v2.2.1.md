# GAMEBOY LAB v2.2.1 — DMG Render-Path Efficiency

v2.2.1 is a deliberately small maintenance release. It keeps the v2.2.0
pixel, CPU, APU, mapper, RTC, BIOS, save-state, and timing behavior unchanged
and removes avoidable dispatch from the Game Boy's packed-colour hot path.

## What changes in games

- DMG background and sprite pixels now select their already-converted packed
  colour directly from the four-entry palette table. The same path is used by
  ordinary whole-line rendering and by the dot-sensitive renderer used after a
  mid-scanline register write.
- In practice, this helps scenes that render a lot of DMG pixels every frame:
  scrolling platform backgrounds, tile-heavy status bars, text screens, and
  sprite-rich effects. The saved CPU time is available to the browser's LCD
  shader, audio queue, keyboard input, and UI compositor, so busy scenes have
  more scheduling headroom and are less likely to miss presentation deadlines.
- This is a throughput change, not a frame-rate cheat: the emulated machine
  still runs at the hardware cadence of approximately 59.7275 Hz, and no
  frames are skipped by the core.

## Measured processing improvement

The benchmark used five fresh-process trials per cartridge, 120 warm-up frames,
and 600 measured frames. Every paired checksum (framebuffer samples plus CPU
state) matched v2.2.0.

| Cartridge/model | v2.2.0 median | v2.2.1 median | Change |
| --- | ---: | ---: | ---: |
| Super Mario Land, DMG | 960.27 fps | 977.13 fps | **+1.76%** |
| Link's Awakening, DMG | 1,026.88 fps | 1,103.50 fps | **+7.46%** |
| Pokémon Blue, DMG | 1,436.81 fps | 1,469.39 fps | **+2.27%** |
| Wario Land 3, GBC | 703.17 fps | 720.21 fps | **+2.42%** |
| Shantae, GBC | 682.30 fps | 680.22 fps | **−0.30%** |
| Pokémon Crystal, GBC | 819.24 fps | 835.35 fps | **+1.97%** |

Shantae's −0.30% is within process and host scheduling variance; the change
does not touch its native CGB colour path. These are available-core-throughput
measurements, not gameplay speeds.

## Accuracy and regression checks

- Mealybug Tearoom DMG structural match: **88.7153%**, unchanged from v2.2.0.
- Mooneye applicable production-model acceptance: **66/66**, unchanged.
- Selected Blargg CPU/APU/memory groups: **41/41**, unchanged.
- SameSuite APU: **47/70**, unchanged; revision-sensitive failures remain
  explicitly tracked.
- Project test suite: **56/56**; standalone build, BIOS hashes, save-state
  round trips, RTC, mapper, audio-worklet cadence, and all built-in cartridges
  remain covered.

## Deliberately not changed

This release does not pretend that a palette lookup removes the remaining
hardware gap. A true per-revision PPU FIFO/fetcher, the outstanding SameSuite
APU cases, OAM-corruption/DMA-bus coverage, special cartridge peripherals, and
browser-device input-to-photon/audio measurements remain the next high-value
work. A mid-mode-3 WX reactivation experiment was rejected after it reduced
the full Mealybug score, so it is not included here.
