# GAMEBOY LAB v2.5.7 — WX=6 window scenes line up correctly

This is a focused accuracy release while the larger v3.0 work remains behind
the broad-test gate.

## What you should notice

Some original Game Boy games use a special window position just six pixels
from the left edge. Their window artwork could previously start on the wrong
vertical tile row, making patterned overlays, score panels, and split-screen
effects look scrambled even though the rest of the frame was in the right
place. That edge case now lines up with the hardware reference. Other window
positions, native Game Boy Color games, saves, and normal frames are unchanged.

## Measured improvement

Across the 24-picture DMG reference set, matching moved from **94.9946% to
95.9639%** (**+0.9693 percentage points, +1.02% relative**). The focused WX=6
picture moved from **74.8698% to 98.1337%** (**+23.2639 percentage points,
+31.07% relative**); the other 23 pictures held their scores.

The project regression suite is **64/64**. SameSuite remains **55/78 with 0
timeouts**, representative DMG/CGB frame and CPU checksums remain stable, and
the normal fast rendering path retains its measured browser headroom. v3.0 is
still reserved for a broader revision-aware accuracy milestone.
