# GAMEBOY LAB v2.1.0 — Pixel and Audio Accuracy

v2.1.0 is a measured accuracy and latency release. It replaces timing-sensitive
whole-line rendering with a dot-sensitive transfer path, substantially expands
APU edge behavior, improves RTC persistence, removes artificial key-release
latency, and adds a genuinely lower-latency audio profile.

## Measured changes from v2.0.0

- SameSuite APU: **11/70 → 47/70**, a gain of **51.43 percentage points** and
  **327.27% more passing cases**.
- Mealybug Tearoom DMG structural image match: **82.7421% → 86.6361%**, a gain
  of **3.8940 points** or **4.71% relative**.
- Mooneye applicable production-model acceptance held at **66/66** and
  emulator-only held at **28/28**.
- The selected Blargg CPU, DMG/GBC audio, and memory set held at **41/41**.
- Minimal audio buffering targets **8 ms at 48 kHz**, **50% below** the previous
  lowest 16 ms target.
- Peak adaptive resampling correction fell from 0.8% to 0.25%: **68.75% less
  maximum pitch/time deviation**.
- The emulated key-up event no longer waits for the decorative 50 ms shell
  animation, removing **up to 50 ms of artificial release delay**.

## Core accuracy

- Live dot-sensitive PPU transfer state for mid-line register changes.
- Fine-scroll discard, window activation, sprite-fetch stalls, and dynamic
  mode-3 completion, including complete in-flight save-state restoration.
- Corrected HDMA working registers/cancellation, blocked mode-3 palette access
  with auto-increment, and an `EI`→`HALT` interrupt edge.
- Pulse duty/trigger/restart state, midpoint PCM reads, wave latching and
  retrigger, noise startup periods, envelope period zero, and frame-sequencer
  edge behavior.
- MBC3 sub-second phase persistence, invalid-value rollover, and fractional
  phase preservation across RTC halt/resume.

## Efficiency

The more exact renderer adds work only when a line becomes timing-sensitive.
Steady lines use cached decoded tile rows, packed framebuffer writes, reusable
sprite records, and allocation-free per-line priority tracking. Alternating-order
paired benchmarks improved five of six games:

| Game | Change |
| --- | ---: |
| Super Mario Land | +2.61% |
| Link's Awakening | +9.65% |
| Pokémon Blue | +31.26% |
| Wario Land 3 | -9.99% |
| Shantae | +3.71% |
| Pokémon Crystal | +3.89% |

Wario Land 3 remains above 700 core frames/s on the audit machine—more than
11× the native cadence. Its regression is disclosed rather than hiding an
accuracy/performance trade-off inside an average.

## Browser audio and controls

- Added Minimal, Low, Balanced, Stable, and Deep queue profiles.
- Narrow symmetric queue correction reduces latency drift without deleting
  audio blocks or changing the emulated APU clock.
- DMG and GBC now use their separate documented analog coupling curves,
  converted to the active host sample rate.
- Visual button travel remains playful while hardware key releases are applied
  immediately.

## Evidence and remaining limits

The conformance and benchmark runners now recognize SameSuite completion,
respect forced hardware models, alternate benchmark order, and compare Mealybug
reference frames without depending on palette colors. The full commands,
methodology, rejected experiments, revision exclusions, and remaining gaps are
recorded in `EMULATION_AUDIT.md`.

This release does not claim that finite test suites prove world-leading
accuracy. The clearest remaining gaps are Mealybug at 86.6361% structural
similarity, 23 outstanding SameSuite APU cases, special cartridge hardware,
and real-device browser latency measurement.
