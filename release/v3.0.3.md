# GAMEBOY LAB v3.0.3

## Summary

This release is a documentation and presentation pass backed by a fresh,
controlled comparison run. The public README now leads with player-relevant
outcomes and uses the current supplied screenshots. The library toolbar is
shorter and clearer, its actions have a consistent hover response, and the
LCD controls no longer crowd the next panel.

The conformance work also closes an important measurement gap: SameSuite and
Mooneye now use the same pinned ROM identities and explicit BIOS/revision
policy for LAB and SameBoy. Gambatte remains visible in the comparison, but
its diagnostic observations are not promoted to a strict score where its
public API cannot prove the test protocol.

## Player-facing changes

- Library search now says **SEARCH** and Add ROM no longer carries a changing
  count in its label.
- Detail, tabletop, and empty-state actions share a small lift, coloured shadow,
  and pressed-state animation.
- The Game Boy contrast slider has the same spacing rhythm as the panel below
  it.
- The README has been rewritten around the single-file, offline experience,
  saves, displays, controls, and practical performance outcomes.
- All three current supplied screenshots are used in the README; the retired
  screenshot set is no longer referenced.

## Controlled comparison

Test host: Apple M1 Pro MacBook Pro (16 GB), 3 August 2026.

### Accuracy suites

| Suite | GAMEBOY LAB | SameBoy 1.0.3 | Gambatte-libretro |
| --- | ---: | ---: | --- |
| SameSuite (76 non-SGB CGB ROMs) | 60 pass / 16 fail | 65 pass / 11 fail | 8 diagnostic pass / 61 diagnostic fail / 7 unavailable |
| Mooneye acceptance (70 applicable ROMs) | 70 pass | 70 pass | Not comparable: CPU marker unavailable |
| Mealybug DMG-blob (24 image ROMs) | 1 exact, 96.0343% average structural match | Not scored: no shared breakpoint framebuffer | Not scored: no shared breakpoint framebuffer |

SameSuite used ROM manifest `589528fa…e993fb`, suite commit
`f15645fb049a47ea235f6d2c9a033e72d8087901`, revision-aware CGB boot mapping,
an 80-million DMG base-clock cycle budget, and a 30-second process safety
limit. The two SGB cases were excluded from both strict scores. Mooneye used
manifest `fd3e40f3…74a61`, its filename model policy, and the same cycle
budget. Full relative results are in
[`v3.0.3-summary.json`](benchmarks/v3.0.3-summary.json).

The historical SameSuite APU note describes an older test count and is not
used to alter today's denominator. The measured v1.0.3 result is retained as
65/76, with each failure kept in the case report.

### Relative core throughput

The benchmark used identical post-boot Tetris cartridges, a 120-frame warm-up,
600 measured frames, nine rotated-order trials, and no DOM, CSS, LCD shader,
or host-audio work. Only percentage differences are published:

- LAB was **86.9% ahead of SameBoy on DMG** and **48.4% ahead on CGB**.
- The native Gambatte adapter was **357.8% ahead of LAB on DMG** and **446.1%
  ahead on CGB**. This is useful native-core context, not an end-to-end
  browser comparison.

These figures describe host workload headroom. They do not change the
emulated hardware clock or make games run faster than the console.

## Engineering notes

- Added `scripts/reference/sameboy-mooneye-runner.c` and
  `scripts/sameboy-mooneye.mjs` so the reference run uses the same explicit
  opcode/register marker as LAB's Mooneye harness.
- Recorded the test identities and only the relative benchmark outcomes in a
  compact release summary; raw host throughput remains local to the run used
  to calculate the percentages.
- Kept Gambatte's strict-comparison guard intact. Its generic CGB mode and
  public register surface cannot establish SameSuite's revision-specific
  completion contract.
- Updated the rendered HTML after the UI changes and retained the single-file
  build path.

## Verification

- `npm test` — build plus 99 project tests.
- `npm run lint`.
- SameSuite LAB and SameBoy: 76 measured, 0 timeouts, 0 crashes, explicit
  boot-policy verification.
- Mooneye LAB and SameBoy: 70 applicable passes, 5 excluded SGB/AGB cases.
- Three-way benchmark: nine trials per adapter with stable output checksums.
