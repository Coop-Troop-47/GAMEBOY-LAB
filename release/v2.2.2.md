# GAMEBOY LAB v2.2.2 — CGB Render-Path Efficiency

v2.2.2 is a measured rendering-throughput release. It keeps the emulated
hardware behavior from v2.2.1 unchanged and removes repeated colour conversion
work from the native CGB and CGB-compatible live pixel paths.

## What changes in games

- CGB background and object palette RAM is mirrored into a 32-entry packed
  colour cache. Each entry is refreshed when its two palette bytes are written,
  including indexed auto-increment writes; blocked mode-3 writes remain blocked.
- Whole-line rendering and the dot-sensitive renderer used after mid-scanline
  writes now select the already-converted packed colour directly. This is
  especially useful in Pokémon battle scenes, Wario Land scrolling layers,
  Shantae's sprite-heavy scenes, Crystal menus, colour status panels, and other
  games that exercise many CGB tiles and objects per frame.
- The practical effect is more available browser CPU headroom for the LCD
  shader, audio queue, input handling, and UI compositor. It does not speed up
  the emulated machine: CPU/PPU/APU timing and presentation remain locked to
  the Game Boy cadence of approximately 59.7275 Hz.

## Measured processing improvement

The paired benchmark used five fresh-process trials per cartridge, 120 warm-up
frames, and 600 measured frames. Every framebuffer/CPU checksum matched the
v2.2.1 core:

| Cartridge/model | v2.2.1 median | v2.2.2 median | Change |
| --- | ---: | ---: | ---: |
| Super Mario Land, DMG | 1,034.57 fps | 1,055.22 fps | **+2.00%** |
| Link's Awakening, DMG | 1,133.54 fps | 1,180.28 fps | **+4.12%** |
| Pokémon Blue, DMG | 1,494.00 fps | 1,538.71 fps | **+2.99%** |
| Wario Land 3, GBC | 715.53 fps | 730.24 fps | **+2.06%** |
| Shantae, GBC | 688.37 fps | 710.97 fps | **+3.28%** |
| Pokémon Crystal, GBC | 819.26 fps | 854.28 fps | **+4.27%** |

These are available-core-throughput measurements, not gameplay speeds.

## Accuracy and regression checks

- Project unit/core tests: **38/38** passing after adding palette-cache write
  coherence coverage.
- Mealybug Tearoom DMG structural match: **88.7153%**, unchanged.
- SameSuite APU: **47/70**, unchanged, with no timeouts.
- Palette writes, CGB mode, CGB-compatible DMG palettes, mode-3 access
  blocking, save-state restoration, BIOS, RTC, mapper, audio, and built-in
  cartridge checks remain covered by the project suite.
- `npm run lint` and the standalone single-file build pass.

## Deliberately not changed

This release does not claim that a palette cache closes the remaining PPU
accuracy gap. A true revision-aware pixel FIFO/fetcher is still the highest
value rendering task, and the 23 SameSuite APU cases remain tracked. Two
experimental window-timing changes were measured and rejected because they
lowered the complete Mealybug image score; they are not included.
