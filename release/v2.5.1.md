# GAMEBOY LAB v2.5.1 — a little more room for smooth play

This is a small performance patch between the focused accuracy release and
the larger v3.0 milestone.

## What you should notice

The emulator now spends less time walking through sprite layers that are not
being drawn. Games keep the same hardware timing and produce the same frames,
but the browser has more spare time for sound delivery, LCD effects, and the
interface. This is headroom—not a change to the Game Boy's fixed speed.

## Measured improvement

Across six representative built-in games, available core throughput improved
by **+2.17% at the median**, with individual results between **+1.49% and
+2.82%**:

- Super Mario Land: **+2.29%**
- Link's Awakening DX: **+2.82%**
- Pokémon Blue: **+2.44%**
- Wario Land 3: **+2.04%**
- Shantae: **+1.49%**
- Pokémon Crystal: **+1.79%**

Final frame and CPU checksums matched v2.5.0 for every game. The external
audio and DMG picture scores also stayed unchanged: **49/70** SameSuite CGB
audio cases, **92.9402%** Mealybug DMG structural match, and **0** timeouts.

v3.0.0 remains reserved for the larger revision-aware accuracy work. It will
ship only when that work improves the test results while retaining this
performance headroom.
