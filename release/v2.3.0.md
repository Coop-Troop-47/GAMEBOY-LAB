# GAMEBOY LAB v2.3.0 — DMG window timing

v2.3.0 is a focused accuracy release. It improves one of the most visible
remaining DMG LCD edge cases while preserving the fixed machine clock, the
existing CGB renderer, battery saves, audio timing, and the single-file build.

## What changes in games

When a DMG game changes the window position during a scanline, especially at
WX 4–6, the old fast path could decide the line from a coarse screen position.
That could show an old tile for a few pixels, start the window one dot late, or
leave a small seam in a raster effect. The new path follows the discarded
pixels and the hardware fetch queue for this narrow left-edge case.

You will notice this most in games with split status panels, score bars, raster
wipes, and window-based transitions. Ordinary lines are still rendered by the
fast path, and CGB games are intentionally not routed through this DMG-only
change while their revision-specific fetch behavior is being audited separately.

## Measured accuracy improvement

The local Mealybug DMG-blob reference set improved from **88.7153% to
92.9402%** structural frame agreement: **+4.2249 points, or +4.76% relative**.
The three left-edge cases improved as follows:

| Reference case | v2.2.2 | v2.3.0 | Relative change |
| --- | ---: | ---: | ---: |
| WX = 4 | 56.6623% | 99.0061% | **+74.70%** |
| WX = 5 | 61.9358% | 97.2309% | **+56.98%** |
| WX = 6 | 49.1797% | 72.9384% | **+48.31%** |

This is reference-image agreement, not a claim that the emulator runs games
faster. The emulated CPU, PPU, APU, and frame cadence remain hardware-timed.

## Performance and safety checks

- Five fresh-process trials across Super Mario Land, Link's Awakening DX,
  Pokémon Blue, Wario Land 3, Shantae, and Pokémon Crystal measured **1.6%
  more median available throughput** than v2.2.2, with every checksum matching.
- Project tests: **58/58** passing.
- SameSuite APU: **47/70** passing, unchanged, with no timeouts.
- The FIFO head, palette, priority, and window-source bytes are now included in
  save states, so restoring during an in-progress DMG window fetch is stable.
- `npm run lint`, the production build, embedded BIOS tests, RTC tests, mapper
  tests, cartridge checks, and Super Mario Land restore checks all pass.

## Scope and v3.0.0 plan

This release is intentionally narrow. It does not claim full equivalence to
every DMG revision, and it does not change the CGB fetcher. v3.0.0 will be the
substantial accuracy release only after the broader revision-aware PPU work and
the outstanding APU edge cases improve together without giving back the
performance headroom.
