# GAMEBOY LAB v3.0.2

This is a maintenance release for the portable build. It removes a redundant
library header, keeps the Add ROM action in the working toolbar, and replaces
the README's broad product copy with a reproducible accuracy summary.

## What changed

- Removed the `40 STORED` / upload reassurance block from the library detail
  view. The toolbar now contains **+ ADD ROM · NN**, where `NN` is the current
  number of cartridges; tabletop mode keeps the matching compact **+ ADD · NN**
  action at the far right.
- Replaced the old detail/table segmented control with one compact brown
  tabletop button. The tabletop drawer close button now shares the same acid
  hover treatment as the other drawer controls.
- Limited the physical console's side push to the viewport range where the
  drawer can actually overlap it. On wide monitors, opening a drawer no longer
  shifts the console away from centre.
- Removed the LCD contrast baseline sentence that repeated information already
  represented by the slider.
- Added the current gameplay, hardware-options, and LCD-options screenshots to
  the README.
- Added an external Gambatte SameSuite diagnostic adapter. It runs all 76
  non-SGB ROMs, but reports the result as diagnostic-only because Gambatte does
  not expose CGB-0/A/B/C/D/E selection or SameSuite's CPU-register callback.

## Verification

All strict comparisons used the same SameSuite checkout (76 non-SGB ROMs), ROM
hash manifest, revision filename policy, boot directory, 80,000,000 DMG-base
cycle budget, 30-second host timeout, and P/F plus Fibonacci-register marker.

| Suite | GAMEBOY LAB | SameBoy 1.0.3 | Gambatte-libretro |
| --- | ---: | ---: | --- |
| SameSuite strict CGB matrix | 60/76 pass | 65/76 pass | not comparable |
| Gambatte SameSuite diagnostic | — | — | 8 byte-level passes / 61 byte-level failures / 7 revision skips |
| Mooneye production acceptance | 70/70 applicable | not run | not comparable |
| Mealybug DMG-blob | 1/24 pixel-exact | not run | not run |
| Project regression tests | 99/99 | — | — |

The 8/61 Gambatte diagnostic result is intentionally not an accuracy claim:
the public Gambatte API cannot prove the register signature at the completion
marker. It is useful for spotting broad behavioural differences, not for
ranking the cores.

The remaining GAMEBOY LAB SameSuite failures are recorded individually in
`EMULATION_AUDIT.md`, with the majority in revision-sensitive APU timing
fixtures. No timeout, crash, or protocol error was counted as a pass.

The existing nine-trial throughput smoke run remains a core-only comparison on
the audit machine. Public notes report only the relative result: LAB was
**+95.3% ahead of SameBoy on DMG** and **+39.4% ahead on CGB** in that run.
The benchmark excludes DOM, CSS, shaders, and host audio, so it describes
available core headroom rather than game speed; raw host throughput is kept
out of public release notes.
