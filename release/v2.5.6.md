# GAMEBOY LAB v2.5.6 — cleaner mid-screen background changes

This is a focused accuracy patch while the larger v3.0 work remains behind a
broader evidence gate.

## What you should notice

On original Game Boy games that turn the background layer on or off while a
line is already being drawn, the change now arrives at the same point as the
hardware's pixel pipeline. Raster wipes, split-screen status panels, HUD
changes, and other mid-screen effects are less likely to show a short block of
pixels from the wrong side of the transition. Native Game Boy Color rendering,
ordinary frames, and saved progress are unchanged.

## Measured improvement

Across the 24-picture DMG reference set, matching moved from **94.9047% to
94.9946%** (**+0.0899 percentage points, +0.09% relative**). The focused
background-toggle picture moved from **88.3420% to 90.4991%** (**+2.1571
percentage points, +2.44% relative**); the other 23 pictures held their
scores.

The project regression suite is **63/63**. SameSuite remains **55/78 with 0
timeouts**, and representative DMG/CGB frame and CPU checksums remain stable.
The normal fast path stays allocation-free; v3.0 is still reserved for a much
larger revision-aware accuracy gain that preserves browser headroom.
