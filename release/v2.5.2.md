# GAMEBOY LAB v2.5.2 — cleaner DMG raster effects

This is a focused accuracy patch while the larger v3.0 revision work remains
under test.

## What you should notice

DMG games that change their colour mapping in the middle of a scanline now
keep the same order and timing as the reference hardware more often. In
practice, raster wipes, status bars, split-screen effects, and scene changes
show fewer misplaced colour bands or one-row seams. If a transfer finishes a
little late, the visible line is completed from the live LCD path instead of
showing pixels left behind by the previous row.

## Measured improvement

The 24-case DMG picture suite improved from **92.9402% to 94.1665%** structural
frame agreement: **+1.2263 percentage points (+1.32% relative)**. The project
regression suite is **59/59**, and SameSuite completed with **55/78** passing
cases and **0** timeouts, unchanged in the cases covered by the previous
release.

Across six representative built-in games, available browser headroom measured
**+1.65% at the median**, with individual results between **+1.12% and
+3.08%**. This is spare time for the browser's audio, shader, and interface
work—not a faster emulated Game Boy clock. Super Mario Land, Link's Awakening
DX, Pokémon Blue, Wario Land 3, Shantae, and Pokémon Crystal all kept the same
frame/CPU checksums as v2.5.1.

v3.0.0 is still deliberately gated. It will be a larger release only after
revision-aware PPU/APU changes improve the broad accuracy results without
giving back this performance headroom.
