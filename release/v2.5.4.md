# GAMEBOY LAB v2.5.4 — cleaner DMG scrolling effects

This is a small accuracy release. It improves a very specific Game Boy
screen effect while keeping the larger v3.0 accuracy milestone behind the
full test gate.

## What you should notice

Some Game Boy games change the vertical scroll position while a scanline is
already being drawn. The handoff now happens over the same tiny fetch window
seen on the original hardware, so split-screen scenes, scrolling status bars,
and raster wipes are less likely to show a short row from the wrong part of
the background. Normal scrolling and native Game Boy Color rendering are
unchanged.

## Measured improvement

The 24-picture DMG reference set moved from **94.6823% to 94.7014%**:
**+0.0191 percentage points (+0.02% relative)**. The focused scrolling picture
rose from **82.5391% to 82.9991%**: **+0.46 percentage points (+0.56%
relative)**. The other 23 pictures held their previous scores.

The project regression suite is **61/61**. Six representative games keep the
same frame and CPU checksums, so saves, input timing, and the fixed Game Boy
clock are unchanged. This patch makes no broad speed claim; the everyday
rendering path remains the same fast path. v3.0.0 is still reserved for a
larger, revision-aware accuracy gain that also preserves browser headroom.
