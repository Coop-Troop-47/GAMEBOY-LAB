# GAMEBOY LAB v3.0.0 — production accuracy and performance

GAMEBOY LAB v3.0 is a measured DMG/GBC accuracy and efficiency milestone. It
targets the production DMG and GBC BIOS files supplied with the project. The
production-model acceptance set passes 66/66 applicable Mooneye checks with no
timeouts; four additional Mooneye ROMs are DMG0/MGB firmware tests and are
reported separately because those historical boot ROMs are not the supplied
production BIOS. This release does not claim that every historical Game Boy
revision has identical timing.

## What players will notice

- Scrolling scenes, status panels, and raster effects on the original Game Boy
  keep their tile rows lined up more reliably. The focused SCY timing reference
  improved from 82.9991% to 84.6875% (2.03% relative).
- Monochrome games running in GBC mode now keep vertical scrolling and mid-frame
  palette changes in the correct fetch phase, so compatibility-mode effects are
  less likely to tear or shift by a tile.
- Wave-channel mute behavior is corrected. Games that turn the wave channel
  down to zero no longer receive a stale full-volume tail, reducing clicks and
  false low-frequency noise around sound effects.
- The audio mixer does less redundant work during silent sections while keeping
  the same hardware clock and sample boundaries. This gives busy scenes more
  headroom without making gameplay run faster or changing the sound schedule.
- The one-file build has more CPU headroom in paired runs: the latest five-trial
  measurement was **23.83% higher on DMG** and **14.07% higher on CGB** than
  v2.5.7. Frame checksums were unchanged, so this is more time for the browser
  to keep up—not faster-than-hardware gameplay.
- The full project regression suite is green at **73/73**. Representative DMG
  and CGB frame/audio checksums remain unchanged, and save-state data remains
  compatible.

## Technical notes

The core now uses exact finite-state audio lookup tables, a dirty mixer cache,
silent-interval integration, allocation-free register-pair reads, tile-row
spans in the write-free background renderer, and a guarded direct cartridge
fetch path after boot/DMA hazards are clear. The live PPU path adds an explicit
DMG SCY fetch handoff, CGB vertical-row latching, and the measured
compatibility-mode BGP handoff. These are narrow timing corrections with
serialized state fields where needed; the CPU/PPU/APU cadence is unchanged.

The available SameSuite run is **55/78 with 0 timeouts**. Its remaining cases
are revision-sensitive CGB/APU/SGB diagnostics rather than silently counted as
production failures. Mealybug structural diagnostics also include CPU C and D
reference sets; those numbers are useful for tracking revision-specific drift,
not a promise of one browser profile matching all historical silicon.

The standalone asset is the generated `public/gbc-lab.html` file and includes
the application, emulator, supplied legal BIOS files, built-in library data,
artwork, and local save support.
