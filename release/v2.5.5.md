# GAMEBOY LAB v2.5.5 — stable long-running window scenes

This is a focused Game Boy accuracy release. It keeps the larger v3.0 work
behind the broad accuracy and performance gate.

## What you should notice

The Game Boy's window overlay uses a small hardware counter that wraps around
after 256 rows. Long-running games that repeatedly open, close, or scroll a
window no longer slowly drift into the wrong tile rows after the counter wraps.
This is most visible in HUD panels, patterned overlays, and repeated split-screen
effects. Normal gameplay timing and native Game Boy Color rendering are
unchanged.

## Measured improvement

The 24-picture DMG reference set moved from **94.7014% to 94.9047%**:
**+0.2033 percentage points (+0.21% relative)**. The focused window scene rose
from **85.2778% to 90.1563%**: **+4.8785 percentage points (+5.72%
relative)**. The other 23 pictures held their previous scores.

The project regression suite is **62/62**. SameSuite remains **55/78 with 0
timeouts**, and representative games keep their frame/CPU checksums. No broad
speed headline is claimed for this patch; the normal fast path and fixed
Game Boy clock remain unchanged. v3.0.0 is still reserved for a wider,
revision-aware accuracy gain that preserves browser headroom.
